# Scales 1.3

The weight graph on Today is now 200 dp tall. Labelled horizontal gridlines show weight in your selected units. The axis fits the readings and visible trend from the past month, with padding around the plotted values and a minimum span of 1 kg or 2 lb. Small day-to-day changes stay in proportion even when your weight is steady.

The chart sits between the latest weigh-in and daily tasks. Its violet line draws across on opening Today, and a new saved reading gets a brief pulse.

Install `Scales-1.3.apk` over Scales 1.2 to keep your measurements and settings. This release uses the same Android package and signing certificate. [Download the APK](https://github.com/smartdevuk/Scales/releases/download/v1.3/Scales-1.3.apk) · [Validation](../VALIDATION.md)
